# Decoy Effect (asymmetric dominance)

**What it is:** Adding a third option that is clearly worse than one option (the "target") but not clearly worse than the other makes people choose the target more often. The decoy exists to make the target look like a good deal, not to be bought.

First shown by Huber, Payne & Puto (1982), *Journal of Consumer Research*. Popularised by Dan Ariely's *Predictably Irrational* (2008) with an Economist subscription example: web only $59, print only $125, print + web $125. Almost nobody chose print only, but its presence pushed people toward print + web.

## How to apply it

1. Decide which option you *want* people to choose (the target), usually the best margin.
2. Create a decoy that is close to the target on price but clearly worse on value (fewer features, smaller size).
3. The decoy must be "asymmetrically dominated": worse than the target on every dimension, but not worse than the cheaper option on every dimension.
4. Test it. Track the share of the target option before and after.

## Worked example

Popcorn: small $5, large $10. Many buy small. Add a medium at $9.50: large is only 50 cents more for much more popcorn, so it now looks like the obvious pick. Strictly this is a *near*-decoy (medium is slightly cheaper, so large doesn't beat it on every dimension), which is how most real menus use the effect. For a pure decoy, price the medium at $10 too.

SaaS: Basic $19 (3 users), Pro $49 (unlimited users, integrations). Add Plus at $49 (10 users, no integrations). Plus is worse than Pro on everything at the same price, but not clearly worse than Basic (it has more users), so it is a true decoy. Pro now looks like the smart choice.

## Common mistakes

- A decoy so attractive people actually buy it (it is then just a new tier, which may cannibalise).
- Decoys that are obviously fake. They erode trust.
- Assuming it works with real products as reliably as in textbook demos (see evidence).

## Evidence

Strong and repeated in lab studies with abstract or numeric options. Weaker outside tidy numeric setups: Frederick, Lee & Baskin (2014, *Journal of Marketing Research*) found the effect often vanished or reversed when options were shown as real or perceptual products rather than attribute tables. Field evidence is thin either way. Treat it as a hypothesis to A/B test, not a guaranteed lift.

Ethics note: it is a nudge, not a trick, as long as every option is real and honestly described.
